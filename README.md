Hartley Household Budget — a working household budget site for a family of four: a monthly dashboard with income vs spending and a savings rate, a transactions ledger with add/edit/delete, search and category filters and a running balance, budgets by category with editable limits, bills and recurring payments you can mark paid, savings goals with contributions, and reports with a six-month income-vs-spending chart and a category breakdown. Everything runs from static files with no network requests, and your changes are saved in the browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `app/index.html` in any static server. To hand the site in as the entry program does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
